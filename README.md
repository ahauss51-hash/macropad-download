# Macropad

Logiciel Windows pour piloter le **Mirabox 293S (V3)** avec SolidWorks, Spotify et Windows, sans le logiciel Stream Dock.

## Télécharger

👉 **[Télécharger la dernière version (Macropad.zip)](https://github.com/ahauss51-hash/macropad-download/releases/latest/download/Macropad.zip)**

Toutes les versions : [page des versions](https://github.com/ahauss51-hash/macropad-download/releases).

## Ce que fait Macropad

- **Pages de touches entièrement paramétrables** : tu crées tes pages, tes dossiers et tes touches depuis un éditeur qui montre le boîtier avec l'emplacement des boutons.
- **SolidWorks** : toutes les commandes SolidWorks sur une touche, tes macros VBA (`.swp`), état du document (configuration, non enregistré, reconstruction, esquisse sous-contrainte).
- **Pavé numérique automatique** : il s'affiche tout seul quand tu modifies une cote, avec une 2ᵉ page pour ajuster la valeur (+1, +10, ×2, ÷2…).
- **Changement de page automatique** (au choix, dossier par dossier) selon le document ouvert.
- **Rappel d'enregistrement** : la touche Enregistrer clignote après 15 min de modifications non enregistrées (réglable).
- **Spotify et multimédia** : lecture/pause, suivant, volume, titre en cours.
- **Écran latéral** du 293S : heure, semaine, état SolidWorks, texte libre.

## Installation

1. Télécharge `Macropad.zip` et dézippe-le où tu veux (par exemple dans `Documents`). Garde le dossier entier.
2. Ferme le logiciel Stream Dock s'il est installé.
3. Branche le 293S et lance **`Macropad.exe`**. Rien d'autre à installer (pas besoin de Python).

Macropad arrive avec une disposition prête à l'emploi (pages, dossiers et touches SolidWorks, pavé numérique). Tu peux tout modifier ensuite dans l'éditeur.

Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » → « Exécuter quand même ».

## Compatibilité

- Windows 10 / 11 (64 bits)
- Mirabox 293S V3
- SolidWorks 2023 (les versions proches devraient fonctionner)

## Mettre à jour

Dans Macropad : **Réglages (⚙) → Mise à jour → Installer une mise à jour…** puis choisis le fichier `app.zip` de la nouvelle version. Ta disposition et tes réglages sont conservés.
